# 골프 스윙 "프로 고스트" 오버레이

같은 샷을 찍은 **정면(face-on) + 후방(down-the-line)** 두 영상을 받아,
골퍼 본인과 **체형·셋업이 같은 프로 3D 모델**을 반투명으로 겹쳐 그리는 도구입니다.
어드레스에서는 고스트와 몸이 정확히 겹치고, 스윙 중에 어긋나는 부분이 곧 고칠 부분입니다.

> 개인 스윙 영상과 결과물(mp4, npz 등)은 `.gitignore`로 저장소에 올라가지 않습니다.

## 파이프라인

| 단계 | 스크립트 | 내용 |
|---|---|---|
| 1 | `tools/extract_pose.py` | MediaPipe Pose Landmarker(heavy)로 프레임별 33개 관절 추출 |
| 2 | `tools/calib.py` | 어드레스 자세 하나로 **두 카메라를 동시 보정**(번들 조정: 3D 관절 + 카메라 자세·초점거리·왜곡). 골퍼 좌표계 G 정의: X=타깃, Y=위, Z=공 쪽 |
| 3 | `tools/ball.py` | 두 뷰의 공 픽셀 좌표로 공의 3D 위치 삼각측량 |
| 4 | `tools/user3d.py` | 두 뷰 삼각측량으로 머리·어깨·골반·손의 3D 궤적과 P1~P10 지표 출력 |
| 5 | `tools/pro_model.py` | 사용자 뼈 길이·어드레스를 그대로 쓰는 운동학 모델. 투어 평균 수준의 P1~P10 키프레임(골반 이동·회전, 척추축 회전, 척추 기울기, 왼팔·클럽 방향)을 매끄럽게 보간 |
| 6 | `tools/render.py` | 고스트를 두 카메라로 투영해 반투명 합성 → 정면/후방/좌우 비교 영상 + 키프레임 시트 |
| - | `tools/preview.py` | 키프레임별 막대 인형 미리보기(키프레임 조정용) |

고스트는 사용자의 P1~P10 프레임(`keyframes.json`)에 시간을 맞추므로, 화면의 차이는 **템포가 아니라 위치·자세 차이**입니다.

## 실행

```bash
pip install -r requirements.txt   # Linux 컨테이너에선 libegl1, libgles2 도 필요
./run.sh front.mp4 dtl.mp4 work/
# 공 위치가 다르면: BALL_FRONT_U=.. BALL_FRONT_V=.. BALL_DTL_U=.. BALL_DTL_V=.. ./run.sh ...
```

`work/keyframes.json`에 본인 스윙의 P1(테이크어웨이 시작)~P10(피니시) 프레임 번호를 넣고 4~6단계를 다시 돌리면 됩니다.

## 한계

- 프로 모델은 특정 선수가 아니라 **투어 평균 바이오메카닉스 값을 바탕으로 만든 모델**입니다.
- 거리 값은 MediaPipe 체형 스케일 기준 추정치입니다(±2~3cm 수준 오차 가정).
- 단안 포즈 추정 특성상 가려진 관절(후방 뷰의 왼쪽 팔 등)은 덜 정확합니다.
