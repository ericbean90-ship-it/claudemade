1. PDF에서 텍스트를 뽑을 때 파일당 약 20%가 잘려 나가고 있었습니다(99쪽 중 약 80쪽만 추출). 이 때문에 **2대질병급여주요검사비지원특약** 등 39개 특약이 아예 보이지 않았습니다. 지금은 원본 PDF를 직접 파싱해 **2,398쪽 전량**을 확보했고, 목차의 168개 특약이 본문에 모두 존재함을 대조 확인했습니다.
2. 이전 정리본의 "70+뇌혈관질환진단특약" 항목에서 비어 있던 지급금액표도 이번에 원문을 확보해 채웠습니다(§5-3).

## 1. 모든 특약 공통 — 제1편 일반사항 (제1-1조~제1-15조)

가장 먼저, 그리고 가장 중요하게 알아두셔야 할 부분입니다. **168개 특약 전부가 이 15개 조항을 각자 베껴 쓰는 게 아니라, 약관 55쪽에 딱 한 벌만 실린 "[특약약관] 제1편 일반사항"을 참조**합니다. 각 특약 첫머리에는 예외 없이 이 문장이 있습니다.

> "[특약 약관] 제1편 일반사항 제1-1조부터 제1-15조까지의 규정을 이 특약 제1편 일반사항으로 합니다."

즉 이 15개 조항은 **물리적으로 공유되는 단 하나의 원문**이므로, 특약별로 달라질 여지가 구조적으로 없습니다.

| 조항 | 핵심 내용 |
|---|---|
| 제1-6조 | 계약 전 알릴 의무(=상법상 고지의무). 청약서 질문에 사실대로 답해야 함 |
| 제1-7조 | 고지의무 위반 시 해지·보장제한 가능. 단, 다음은 예외: ①회사가 이미 알았거나 과실로 몰랐을 때 ②안 날부터 1개월 경과 ③보장개시 후 2년 경과(진단특약 질병은 1년) ④체결 후 3년 경과 ⑤건강진단서에 명기된 사항 ⑥설계사가 고지를 방해했을 때 |
| 제1-8조 | 사기에 의한 계약은 보장개시일부터 5년 이내(안 날부터는 1개월 이내) 취소 가능 |
| 제1-9조 | 청약 후 30일 이내 승낙/거절 통지 필요, 통지 없으면 승낙 간주 |
| 제1-10조 | 나이 미달·초과로 가입 시 특약 무효 |
| 제1-11조 | 특약 보험료는 주계약 보험료와 함께 납입 |
| 제1-12조 | 보험료 연체 시 14일 이상 납입최고(독촉) 후 해지 |
| 제1-13조 | 연체로 해지된 특약도 해지일부터 3년 이내 부활(효력회복) 신청 가능 |
| 제1-14조 | 위법계약 해지: 체결일부터 5년 내, 위반 안 날부터 1년 내 요구 가능 |
| 제1-15조 | 고의 사고 유발, 서류 위·변조 시 회사가 1개월 이내 해지 가능 |

**비유하자면**: 이 15개 조항은 아파트 단지의 "공동 관리규약"입니다. 각 세대(특약)가 규약을 새로 만드는 게 아니라, 규약집은 단지에 한 권만 있고 각 세대 계약서에 "우리 단지 관리규약을 따른다"고 한 줄 적어 두는 구조입니다.

### 지급금액에서 반복되는 3가지 패턴

168개를 훑어보면 지급금액 문구는 사실상 아래 세 틀의 조합입니다. 이것만 외워 두시면 개별 특약은 숫자만 갈아 끼우면 됩니다.

1. **1년 룰** — 계약일부터 1년 초과면 100%, 1년 이내면 50%. (갱신형은 "**최초계약의** 계약일" 기준이라 갱신해도 다시 50%로 돌아가지 않습니다.)
2. **3종 할인 룰** — 3종(간편고지형)은 1년 이내 사고 중 **재해가 원인이면 1·2종과 동일**, 재해 외 원인이면 절반.
3. **연 1회/최초 1회 한도 룰** — 진단금은 대개 "최초 1회", 치료·검사비는 "보험연도 기준 연 1회", 입원·간병은 "1회 입원당 며칠 한도".

## 7. 알아두시면 도움 되는 개념 비유

- **무배당·무해약환급금형**: "보험료를 낮게 받는 대신, 납입기간 중 해지하면 돌려줄 돈이 없는" 구조입니다. 헬스장 "저가 연간회원권을 끊었는데 중도 해지 시 환불이 안 되는 것"과 비슷합니다.
- **상품명 끝의 "C"**: 피보험자가 보험기간 중 사망해 특약이 소멸할 때 계약자적립액을 **주는 형/안 주는 형** 두 가지로 운영한다는 표시입니다. 두 형 모두 같은 약관을 씁니다.
- **체증형(예: 5년마다 10%씩 증가)**: 물가상승률을 반영하듯, 가입 후 시간이 지날수록 같은 사고라도 받는 보험금이 조금씩 커지는 구조입니다.
- **계약 전 알릴 의무 위반의 "2년/3년 룰"**: 회사가 미처 확인하지 못했더라도, 일정 기간(보장개시 후 2년, 계약 후 3년)이 지나면 더는 문제 삼지 못하게 한 "시효" 같은 장치입니다.
- **1종/2종/3종**: 1종=건강고지형, 2종=일반고지형, 3종=간편고지형. 3종은 고지 문턱이 낮은 대신 **가입 1년 이내 재해 외 원인**의 보험금이 절반으로 깎입니다. 168개 중 153개가 이 3종 체계를 씁니다.
