## 1. 제1편 일반사항 (제1-1조~제1-15조)

168개 특약 전부가 이 조항을 **각자 복제하지 않고 약관 55쪽의 단일 원문을 참조**합니다.
각 특약 첫머리 문구: *"[특약 약관] 제1편 일반사항 제1-1조부터 제1-15조까지의 규정을 이 특약 제1편 일반사항으로 합니다."*
→ 따라서 이 15개 조항은 **특약별로 달라질 여지가 구조적으로 없습니다.**

| 조항 | 내용 |
|---|---|
| 제1-1조~제1-5조 | 특약의 체결·보험금 청구·지급절차 등 기본사항 |
| 제1-6조 | 계약 전 알릴 의무(고지의무). 청약서 질문에 사실대로 답해야 함 |
| 제1-7조 | 고지의무 위반 시 해지·보장제한. **예외 6가지**: ①회사가 이미 알았거나 과실로 몰랐을 때 ②안 날부터 1개월 경과 ③보장개시 후 2년 경과(진단특약 질병은 1년) ④체결 후 3년 경과 ⑤건강진단서 명기사항 ⑥설계사가 고지를 방해 |
| 제1-8조 | 사기에 의한 계약은 보장개시일부터 5년 이내(안 날부터 1개월 이내) 취소 가능 |
| 제1-9조 | 청약 후 30일 이내 승낙/거절 통지 필요. 통지 없으면 승낙 간주 |
| 제1-10조 | 나이 미달·초과로 가입 시 특약 무효 |
| 제1-11조 | 특약 보험료는 주계약 보험료와 함께 납입 |
| 제1-12조 | 보험료 연체 시 14일 이상 납입최고(독촉) 후 해지 |
| 제1-13조 | 연체로 해지된 특약도 해지일부터 3년 이내 부활(효력회복) 신청 가능 |
| 제1-14조 | 위법계약 해지: 체결일부터 5년 내, 위반 안 날부터 1년 내 요구 가능 |
| 제1-15조 | 고의 사고 유발, 서류 위·변조 시 회사가 1개월 이내 해지 가능 |

## 2. 제2편 공통 조항

보장특약 160개가 아래 조항 골격을 **조항번호·제목까지 동일하게** 사용합니다(제도성특약 8개는 제2편 없음).
특약마다 실제로 달라지는 것은 **제2-1조(정의)·제2-2조(지급사유·금액)·제2-3조(지급 세부단서)·제2-12조 일부(고유 소멸사유)** 뿐입니다.

| 조항 | 제목 | 공통 내용 |
|---|---|---|
| 제2-4조 | 보험료 납입면제 | 주계약 납입면제 사유 발생 시 이 특약도 차회부터 면제. 동일 재해로 장해지급률 합산 50% 이상이어도 면제 |
| 제2-5조 | 장해지급률 산정 | 재해일부터 180일 이내 장해상태가 확정되지 않으면 180일째 의사 진단 기준으로 결정 |
| 제2-6조 | 보험금 미지급 사유 | ①피보험자가 고의로 자신을 해친 경우 ②보험수익자가 고의로 피보험자를 해친 경우 ③계약자가 고의로 피보험자를 해친 경우. **단 피보험자가 심신상실 등으로 자유로운 의사결정을 할 수 없는 상태에서 자신을 해친 경우는 지급** |
| 제2-7조 | 사고증명서 | 보장 종류별로 요구 서류가 다름(진단서·입퇴원확인서·수술확인서·간병인 사용 증빙 등) |
| 제2-8조 | 보험금 받는 방법의 변경 | 미적용 |
| 제2-9조 | 보험수익자의 지정 | 미지정 시 피보험자를 보험수익자로 함 |
| 제2-10조 | 피보험자의 범위 | 주계약 피보험자와 동일 |
| 제2-10조의2 | 특약의 갱신 | **142개 특약은 '해당사항 없음'. 갱신형 26개에만 적용** — 계약자가 보험기간 만료 15일 전까지 유지하지 않겠다고 통지하지 않으면 자동 갱신. 갱신 시 보험료는 갱신일 나이·기초율로 재산정 |
| 제2-10조의3 | 무효에 관한 특칙 | 3종(간편고지형) 가입자가 계약일부터 3개월 이내에 1·2종 가입 가능 판정을 받으면 특약 무효, 보험료 반환 |
| 제2-11조 | 특약내용의 변경 등 | 주계약 변경 시 동일하게 변경. 보험기간·납입기간 변경은 제한 |
| 제2-12조 | 특약의 소멸 | **공통 소멸사유 3가지**: ①주계약이 해지·무효·취소·철회된 경우(단, 특약 보험료 납입완료 후 주계약이 해지됐어도 해약환급금을 받지 않았으면 보장 유지) ②피보험자가 보험기간 중 사망한 경우('사망시 계약자적립액 지급형'은 적립액 지급) ③보험기간 만료. **특약별 추가 소멸사유는 `01_특약별_지급사유.md`에 기재** |
| 제2-13조 | 계약자의 임의해지 | 계약자는 언제든지 해지 가능, 해약환급금 지급 |
| 제2-14조 | 해약환급금 | 산출방법서에 따름. **무해약환급금형은 보험료 납입기간 중 해지 시 해약환급금 없음** |

## 3. 지급금액 3대 패턴

168개 특약의 지급금액 문구는 사실상 아래 세 틀의 조합입니다.

### 패턴 1 — "1년 룰" (감액기간)
- 계약일부터 **1년 초과**: 특약보험가입금액의 **100%**
- 계약일부터 **1년 이내**: **50%**
- **갱신형 특약은 "최초계약의 계약일" 기준** → 갱신됐다고 다시 50%로 돌아가지 않음
- 일부 특약(독감 등)은 1·2종에 **90일 룰**을 적용
- "계약일부터 1년 이내"란 계약일부터 1년이 되는 시점의 **계약해당일 전일까지**

### 패턴 2 — "3종 할인 룰"
- 3종(간편고지형)은 1년 이내 사고 중 **재해가 원인이면 1·2종과 동일 지급**
- **재해 이외의 원인**이면 1년 초과 시 지급액의 **50%**
- 이 감액은 **1종(건강고지형)·2종(일반고지형)에는 적용하지 않음**
- 168개 중 **153개**가 1·2·3종 체계를 운영

### 패턴 3 — "횟수 한도 룰"
- **진단금**: 대개 "최초 1회에 한함" (지급과 동시에 특약 소멸하는 경우 많음)
- **치료비·검사비**: "보험연도 기준 연 1회"
- **입원·간병**: "1회 입원당 N일 한도" (180일 / 30일 등)
- **진단 후 N년형**: 최초 진단확정일부터 10년간, "진단후 보험연도" 기준 연 1회(최대 10회)

### 전 특약 공통 정의

**"보험연도"** — 당해연도 보험계약해당일부터 차년도 보험계약해당일 전일까지 매 1년 단위의 연도. **달력 연도가 아님.** 계약일이 4월 1일이면 보험연도는 4월 1일~차년도 3월 31일. 해당 연도에 계약해당일이 없으면 그 달의 마지막 날을 계약해당일로 함.

**"암보장개시일"** (암 관련 특약 공통) — 계약일(부활일)부터 그 날을 포함하여 **90일이 지난 날의 다음날**. 단 기타피부암·갑상선암·비침습방광암·대장점막내암은 면책기간 없이 계약일부터 보장. 90일 이내에 암 진단 확정 시 계약자는 진단일부터 90일 이내에 특약을 **취소**하고 기납입보험료를 돌려받을 수 있음.
