# 코칭 판정 기준과 리포트 템플릿

## 지표 → 문제 판정 (`metrics.json` 키, 실측 cm/°, 오른손잡이 기준)
| 키 | 문제 | 경고 기준 | 프로 목표 |
|---|---|---|---|
| `head_sway_top_cm` | 백스윙 스웨이 (머리) | > 8 | 3~5 |
| `pelvis_sway_top_cm` | 백스윙 골반 밀림 | > 5 | 0~3 |
| `pelvis_shift_impact_cm` | 다운스윙 체중 이동 부족 | < 6 | 8~12 |
| `spine_loss_impact_deg` | 얼리 익스텐션 (일어서기) | > 4 | 0~3 |
| `pelvis_toward_ball_impact_cm` | 배치기 (골반이 공 쪽으로 나옴) | > 3 | -2~2 |
| `head_impact_cm` | 상체 쏠림 (전환 때 머리가 골반보다 먼저 타깃 쪽으로 감) | > +3 | -2~-8 (공 뒤에 남음) |
| `hands_out_downswing_cm`, `hands_outside_p6_vs_p2_cm` | 엎어치기 (손이 바깥으로 내려옴) | > 6 / > 4 | 0~3 |
| `pelvis_shift_finish_cm`, `spine_fwd_finish_deg` | 피니시가 뒤로 젖혀짐 | < 10 및 < 20 | 왼발 위에 곧게 섬 |
| `tempo_ratio` | 템포 | < 2.5 또는 > 3.6 | 약 3:1 |
| `stance_to_shoulder_ratio` | 스탠스가 넓음 (스웨이 유발) | > 1.25 | 약 1.1 (7번 아이언) |

수치로는 볼 수 없어서 **키프레임 시트로 눈으로 확인할 것**:
- **P2:** 클럽헤드가 손보다 바깥으로 빠지는지
- **P3:** 후면에서 샤프트가 거의 수직인지 (가파른 백스윙)
- **P5~P6:** 샤프트가 눕는지, 아니면 곧게 서서 내려오는지

## 근본 원인 고르기 (하나만)
문제들은 다음 순서로 연쇄적으로 일어납니다.

스웨이 → 상체 주도 전환 → 엎어치기 → 일어서기 → 피니시 뒤로 젖혀짐

이 사슬에서 **가장 앞쪽에 있는, 기준을 벗어난 고리**가 근본 원인입니다.
- **스웨이를 고쳤는데** 머리가 임팩트 때 타깃 쪽으로 3cm 넘게 가 있고 엎어치기가 남으면 → "전환: 골반이 먼저, 머리는 공 뒤에"
  - 스웨이를 고치려다 반대로 상체가 따라 나가는 과교정이 흔합니다.
- **스웨이를 고쳤는데** 체중 이동이 아직 부족하면 → "전환: 왼발 밟고 골반 한 뼘 타깃 쪽으로"
- **체중 이동까지 정상인데** 척추각을 잃으면 → "임팩트까지 엉덩이 뒤 라인 유지"
- **바디가 정상인데** 엎어치기가 남으면 → "전환 때 손을 오른 허벅지 쪽으로 떨어뜨리기 (샬로잉)"

## 근본 원인별 비유와 드릴
| 근본 원인 | 비유 | 드릴 |
|---|---|---|
| 스웨이 | 미닫이문이 아니라 회전문 | 오른 골반 옆 의자/골프백 · 크로스암 피벗 · 오른발 바깥에 공 깔기 · 발 모으고 치기 |
| 체중 이동 부족 | 야구 타자의 앞발 내딛기 | 스텝 스루 드릴 · 왼발 밟고 멈추기(펌프) 드릴 |
| 얼리 익스텐션 | 엉덩이로 벽 밀기 | 엉덩이 뒤에 의자를 대고 임팩트까지 닿게 유지 |
| 엎어치기 | 문고리를 아래로 당기기 | 공 바깥쪽 헤드커버 피하기 · 오른 팔꿈치를 옆구리로 |
| 상체 쏠림 (전환) | 활시위: 하체가 앞으로 당기는 동안 머리는 뒤에서 버팀 | 머리 왼쪽에 기준 스틱 · 펌프 드릴(탑→허리까지 내렸다 다시 올리기) · 오른발 뒤로 빼고 치기 |

## 리포트 템플릿 (이 순서 그대로)
1. **한 줄 요약**: 이번 회차 핵심 변화와 다음 과제
2. **지난 회차 대비 변화**
   - `compare.md` 표를 넣고 좋아짐/나빠짐/변화 없음을 해석합니다.
   - 첫 회차면 "기준선"이라고 씁니다.
3. **문제점 (중요한 순서)**: 표를 넣고 항목마다 한두 줄로 설명합니다.
4. **고칠 것 단 하나**: 근본 원인을 비유로 설명하고, 연쇄가 어떻게 이어지는지 씁니다.
5. **이렇게 치세요**
   - 핵심 느낌 3가지
   - 구간별 동작 (셋업 → 테이크어웨이 → 탑 → 전환 → 임팩트 → 피니시)
   - 드릴
   - 연습 계획
   - 성공 기준 (숫자로)
6. **영상 안내**
   - 파일 목록
   - 보는 법: 하늘색 = 프로, 흰 점선 = 어드레스 때 머리 위치, 주황 점선 = 어드레스 때 샤프트 플레인
7. **한계**
   - 수치는 추정치이고 오차는 ±2~3cm입니다.
   - 영상이 슬로모션이라 템포는 비율로만 의미가 있습니다.
   - 구질 데이터는 없습니다.
